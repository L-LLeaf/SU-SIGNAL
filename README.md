# SU / SIGNAL

A private, local-first communication experience for SU × LIGHT.

## Visual system
- Swiss International Style
- Red `#E32636`, white `#FFFFFF`, charcoal `#171717`, light gray `#EEEEEE`
- Chinese default font: Songti
- Mobile-first; no simulated phone status bar or bottom system navigation
- No sound module

## Applications
CHAT · CARDS · PROFILE · ENGINE · STYLE · NOTICE · DATA · CHOICE

## Product principles
- Exactly two participants: player and Su Xinhao
- Player and Su Xinhao profiles are independently customizable
- Default chat background is the native red/white design; player-uploaded backgrounds are optional
- Player data is local-first and must be included in full backup/export
- Built-in cards are read-only to players and must never be overwritten by player imports
- No multi-character or group-chat feature

## Deployment
This repository is intended for GitHub Pages. The first implementation is a static site with no build step.

## Development status
Phase 01: foundation, access screen, home navigation.
Feature modules are implemented incrementally and tested before being marked complete.
